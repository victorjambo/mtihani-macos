Mtihani 1.1.3

  • Connects to the new Mtihani backend and web client.
  • Allows more time for the backend to wake after inactivity.
  • Fixes a compatibility crash on older supported macOS versions.
  • Includes native support for Intel and Apple silicon Macs.
  • Starts a new automatic-update signing key for this release line. Existing users must install this release manually once.

Requires macOS 15.6 or later. Sign in with Google, configure an AI provider in the web client, and select a session before capturing.

This release is not notarized by Apple. After attempting to open the app, use System Settings > Privacy & Security > Open Anyway if prompted.
