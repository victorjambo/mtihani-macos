Mtihani 1.1.0

This release introduces a redesigned macOS experience with clearer session, capture, permission, update, and account controls.

What's new

  • Redesigned Settings with dedicated Sessions, Capture, Permissions, Updates, and Account sections.
  • Improved sign-in, account restoration, account switching, and sign-out flows.
  • Added session creation, selection, refresh, and manual session-ID entry.
  • Added configurable repeated-click capture controls and display selection.
  • Added clearer Screen Recording permission status and shortcuts to System Settings.
  • Added Sparkle update checks and update preferences.

Menu bar improvements

  • Added the new Mtihani menu-bar icon.
  • Added Capture Now and pause or resume click-capture actions.
  • Moved account actions into a dedicated account submenu.
  • Improved status, active-session, and signed-in account information.

Additional improvements

  • The application is now named Mtihani throughout macOS.
  • Backend connections now consistently use the API URL supplied by the application configuration.
  • Improved update validation, release packaging, and general reliability.
